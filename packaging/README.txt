SnairCreator v0.0.1 beta - Circuit Drift Labs
=============================================

Turn any WAV/AIFF sound into a playable snare or clap.

Formats: Standalone app, VST3, CLAP (and AU on macOS).

Install locations
- Windows VST3: C:\Program Files\Common Files\VST3\SnairCreator.vst3
- Windows CLAP: C:\Program Files\Common Files\CLAP\SnairCreator.clap
- macOS VST3:  /Library/Audio/Plug-Ins/VST3   CLAP: /Library/Audio/Plug-Ins/CLAP   AU: /Library/Audio/Plug-Ins/Components
- Linux VST3:  ~/.vst3                        CLAP: ~/.clap
The portable standalone runs from any folder; settings are kept in your user application-data folder.

Quick start: drop a WAV/AIFF on the window, choose SNARE or CLAP, shape with the macros, press PREVIEW
(or play MIDI), then EXPORT WAV, EXPORT KIT, or drag the generated waveform into your DAW.
Press HELP inside the app for the full guide.

This is a BETA. Builds are unsigned: on Windows choose "More info > Run anyway" if SmartScreen warns;
on macOS right-click > Open the first time (or run: xattr -dr com.apple.quarantine <path>).
No network access, accounts or telemetry.
