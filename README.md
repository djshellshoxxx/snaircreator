# SnairCreator

SnairCreator is a planned JUCE/C++ instrument that turns a user-provided audio source into playable Snare or Clap sounds. The same generated hit is intended to work for preview, MIDI playback, DAW session recall and WAV export.

**Repository status: design/planning only.** The repository has approved product requirements and an implementation plan; it does not yet include the instrument source or built binaries.
